## 유니버설 Windows 플랫폼 개발

PC, 모바일, Xbox, HoloLens, IoT, Surface Hub 등 다양한 장치를 대상으로 앱을 개발할 수 있습니다.

![하나의 플랫폼과 많은 디바이스가 있는 그래픽](https://visualstudio.microsoft.com/wp-content/uploads/2018/06/Opportunity_636x300-1_2.png)

하나의 플랫폼과 많은 디바이스가 있는 그래픽

## 기회

### 단일 플랫폼, 많은 장치

Windows 10은 Windows 10을 실행하는 모든 디바이스에 연결되는 통합 저장소를 제공하여 새로운 수익 기회를 창출합니다. Windows는 모바일, 데스크톱, Xbox 등 모든 장치에서 단일 통합 코어에서 실행됩니다. 하나의 코드베이스로 모든 장치에 연결하고 필요에 따라 런타임에 맞출 수 있습니다.

## 전문 기술 활용

### C#, VB, C++, HTML, JavaScript

C#, Visual Basic, C++ 및 HTML/JS에서 기존 기술을 활용하여 Windows 10 성능을 이용해 차세대 앱을 빌드합니다.

## 코드

### IntelliSense, 탐색, 리팩터링

코드 편집기에서 고급 구문 강조 표시, IntelliSense 코드 완성, 직관적인 소스 탐색으로 생산성을 향상하세요. 강력한 리팩터링 및 중복 코드 탐색 도구를 사용하여 코드베이스를 최적화하고 유지 관리할 수 있습니다.

[Visual Studio를 사용한 편집에 대한 자세한 정보](https://visualstudio.microsoft.com/ko/vs/features/develop/)

## 디자인

### 전문적이고 세련된 환경

XAML 앱용 프리미어 전문 디자인 도구인 Blend for Visual Studio를 사용하여 유니버설 Windows 앱에 맞춘 매력적인 사용자 인터페이스를 만듭니다. Blend의 벡터 드로잉 도구 모음, 강력한 템플릿 편집 기능, 실시간 애니메이션, 시각적 상태 관리 등을 이용해서 뛰어난 변환 및 시각화를 빌드할 수 있습니다.

## 연결

### Azure, Office 365, Salesforce 등

연결된 서비스를 위한 Visual Studio 서비스 관리자를 통해 Azure Mobile Services, Salesforce 및 Office 365와 같은 클라우드 서비스와 쉽게 통합합니다. 서버 탐색기 및 데이터 소스와 같은 기능을 이용해 서버, 서비스, 데이터베이스를 효율적으로 관리합니다.

## 디버그 및 분석

### 문제 해결, 진단, 수정

IntelliTrace, 코드 실행 제어 및 검사, XAML용 UI 디버깅 도구, 예외 이해 및 해결을 위한 뛰어난 환경과 같은 최고 수준의 디버깅 기능을 활용하여 개발 과정을 간소화할 수 있습니다.

[Visual Studio를 사용한 디버깅에 대한 자세한 정보](https://visualstudio.microsoft.com/ko/vs/features/debugging-and-diagnostics/)

## 최적화

### 측정, 식별, 향상

성능 및 진단 허브에서 CPU 사용, 메모리 사용, 네트워크 사용, GPU 사용 및 앱 타임라인과 같은 도구를 사용해서 앱을 최적화할 수 있습니다. 애플리케이션의 리소스 사용을 시나리오 중심으로 확인함으로써 병목 상태를 식별하고 성능을 향상합니다.

## 테스트

### 유효성 검사, 자동화, 관리

Visual Studio 및 Team Foundation Server를 통해 수동 및 자동 테스트, 실험적 테스트, 부하 테스트와 같은 테스트 방식을 채택합니다. Visual Studio의 Lab Management 도구를 사용해 랩 환경에서 빌드, 배포, 테스트 실행을 수행하는 프로세스를 쉽게 자동화할 수 있습니다.
